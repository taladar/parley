Generated by `traversal_font_sensitivity`. Do not edit; run `PARLEY_TEST=accept cargo test -p parley_tests traversal`.

Compares each corpus entry laid out with **Roboto only** against the same entry laid out with **Roboto + Noto Kufi Arabic**. That is a real shaping difference: the bundled tier ligates Arabic lam-alef into one glyph. `yes` means the projection is identical either way.

`ranges_same` is the one that matters: `Cluster::text_range()` is what every cursor, selection and delete operation reads. If it is font-invariant, those operations can be measured without vendoring font assets for scripts the test fonts do not cover.

`no_fonts` is the cluster count with **nothing registered at all** — a degenerate state in which traversal has nothing to walk and silently reports a whole-text index for every query.

## Result

`text_range` differs between the two shaping tiers for **0 of 67 entries**. Cluster text ranges are font-invariant, so cursor motion, selection and deletion are measurable for every entry with the fonts already in tree — including the scripts none of them cover. Vendoring font assets would not change any of those measurements.

`glyph_len` differs for 6 of 67 entries (arabic_base_harakat, arabic_shadda_fatha, arabic_tatweel, bidi_ltr_rtl_ltr, bidi_rtl_only, bidi_rtl_with_combining) — the expected shape of a font mattering at all: it changes what is drawn, not what is traversed.
