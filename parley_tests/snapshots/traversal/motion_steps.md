# Caret motion from every position

Generated by `traversal_motion_steps`. Do not edit; run `PARLEY_TEST=accept cargo test -p parley_tests traversal`.

Measured with the `bundled` font tier. Buffers are rendered as codepoints, never as text.

Each operation applied **once** from every char boundary. Cells are `focus@affinity` (`D`ownstream/`U`pstream), or `anchor-focus@affinity` for a range.

`*` marks a step that changed nothing; `~` marks one that changed only the affinity. Affinity is not swept — the public driver API cannot place a caret at a chosen affinity, so `from` shows what `move_to_byte` snapped to.
