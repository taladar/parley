`parley`'s `complex-scripts` feature switches ICU between dictionary and non-complex word and line breaking for Thai, CJK, Khmer, Lao and Myanmar. CI runs `--all-features`, so the `complex` setting is the one upstream tests; a plain `cargo test -p parley_tests` gets `simple`, which had no coverage at all before this.

The label is **measured, not read off `cfg!`**: feature unification can turn on `parley/complex-scripts` whether or not `parley_tests` forwards it, so a `cfg!` here can disagree with the library under test. Only a dictionary segmenter finds word boundaries inside unspaced Thai, so the fingerprint below decides the label and cannot drift from reality.
