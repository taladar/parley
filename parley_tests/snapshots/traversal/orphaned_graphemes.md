# Graphemes that editing can strand with nothing to render

Generated by `traversal_orphaned_graphemes`. Do not edit; run `PARLEY_TEST=accept cargo test -p parley_tests traversal`.

Measured with the `bundled` font tier. Buffers are rendered as codepoints, never as text.

Breadth-first search over every buffer reachable from the entry by `delete` and `backdelete` at any caret position. A grapheme is **orphaned** when every codepoint left in it has no visual form of its own — a lone ZWJ, a lone variation selector, a lone tag character. The buffer is not empty and the caret still has to cross it, but the user sees nothing there.

- `states` — distinct buffers reachable. The search is exhaustive over them.
- `orphans` — distinct undisplayable graphemes found across all of them.
- `classes` — how many distinct *kinds* those fall into. The per-entry tables list one example of each kind rather than every combination; see `orphans.rs`.
- `presses` — length of the **shortest** press sequence that produces one. `0` means the entry already contained one before any editing, which is a property of the corpus and not of parley.
- Whitespace is not an orphan: a lone newline or tab is an ordinary buffer.
- Word-deletion variants are out of scope; see `orphans.rs`.
