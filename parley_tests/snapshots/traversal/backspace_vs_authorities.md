# Backspace: parley against every reference rule

Generated by `traversal_backspace_vs_authorities`. Do not edit; run `PARLEY_TEST=accept cargo test -p parley_tests traversal`.

Measured with the `bundled` font tier. Buffers are rendered as codepoints, never as text.

Presses to erase each entry with backspace. Every column is executed, not quoted. The reference rules are **clean-room reimplementations from documented behaviour** — parley is Apache-2.0 OR MIT and the sources they describe are Apache-2.0 only, so their code cannot be copied here. They are good enough for whole-sequence-versus-one-codepoint, and no more: see `rules.rs` for what is approximate.

- `egc` — UAX #29 extended grapheme clusters. `CodeMirror` 6 is exactly this.
- `aosp` — Android, as ported by xi-editor and xilem #303.
- `blink` — Chrome. AOSP's rule with `Extended_Pictographic` instead of `Emoji`.
- `pango` — GTK. Script-dependent.
- `qt` — Qt's `QTextCursor` (QtGui), which backs `QTextEdit`, `QPlainTextEdit` and QML `TextEdit`. NOT `QLineEdit`, a separate implementation that was not examined.
- `agree` — whether all five references give the same answer.
- `verdict` — how parley relates to them.

⚠ **`crlf` appears as a conflict only because of an unverified approximation.** Qt documents no CRLF case — its rule is emoji-or-one-codepoint and nothing else — so the `qt` column splits the pair while the other four do not. Whether real Qt behaves that way was not confirmed; a `QTextDocument` normalises newlines, so the case may never arise there. Do not read that row as evidence about Qt.
